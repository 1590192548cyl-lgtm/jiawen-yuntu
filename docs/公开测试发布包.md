## 二、预算与异常监控方案

### 当前已实施

1. 每个随机客户端标识每分钟最多请求 12 次。
2. Worker 固定使用服务端批准的模型，浏览器不能篡改为更昂贵模型。
3. 单次问题最长 1,200 字、家庭画像最长 4,000 字、模型最多输出 500 tokens。
4. Worker 运行日志采用 10% 抽样，用于发现接口错误和异常访问，不在应用代码中记录用户问答正文。

### 上线前人工设置

1. 密钥所有者登录 DeepSeek 开放平台余额页面，确认该密钥为“家稳云图专用”。
2. 优先采用小额预付余额；不要绑定无上限的自动充值。
3. 每周检查一次调用量与余额；比赛展示或集中测试当天增加检查频率。
4. 出现余额异常下降时，立即轮换 API Key，并在 Cloudflare 中更新 `MODEL_API_KEY`。

## 三、隐私政策（预览稿）

### 1. 我们处理哪些信息

家稳云图公开测试版会处理用户主动填写的家庭财务概要，例如月收入、刚性支出、债务还款、应急金覆盖、家庭责任、保障情况和财务目标。页面不要求用户填写真实姓名、身份证号、银行卡号、账户密码或详细住址。

为提供 AI 问答，用户的问题、必要的家庭画像摘要和随机生成的客户端标识会经 Cloudflare Worker 发送至 DeepSeek API。随机客户端标识不包含姓名、手机号或证件号码。

### 2. 处理目的

上述信息仅用于生成家庭财务风险评估、风险缓冲建议、行动清单和 AI 问答，以及保障接口安全、限制异常调用和排查服务故障。

### 3. 存储方式

当前版本不会在家稳云图自建数据库中保存家庭档案。页面刷新后，未提交至其他存储服务的家庭档案不会作为用户账户资料长期保存。AI 服务供应商和基础设施服务商可能按照其服务规则处理请求数据，正式发布前应补充其准确的处理与保存说明。

### 4. 用户注意事项

请勿输入身份证号、银行卡号、账户密码、验证码、详细住址、完整保单号或其他不必要的敏感信息。如果误输入敏感信息，请立即停止继续发送，并通过项目联系渠道申请处理。

### 5. 用户权利

用户可以停止使用服务、清除浏览器站点数据，并通过项目联系渠道提出查询、更正或删除相关信息的请求。项目联系邮箱：`1590192548cyl@gmail.com`。

### 6. 未成年人

未满 18 周岁的用户应在监护人指导下使用本服务，不应独立依据 AI 输出作出金融或保险决定。

### 7. 政策更新

本政策会随功能、服务供应商和法律要求变化而更新。重大变化将通过页面显著位置提示。
